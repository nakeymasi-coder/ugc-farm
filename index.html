Please read — what this dashboard does NOT do: This dashboard by itself does not browse Pinterest, generate images, search TikTok Shop or make videos when you submit a form. How the farm works

The farm takes a run from a Pinterest outfit — or a TikTok Shop product — to a finished 9:16 video, and brings the video back to you in chat for approval. The dashboard holds everything in one place: the full Video Intake Form, solo forms for all 6 agents, the Character Vault for locked characters, and the Queue for every run and solo job.

The 6 agents, in order

1. Pinterest Scout

Searches Pinterest for outfits and products, especially products available on Amazon, for the chosen mode and topic. Works from guest view, no Pinterest sign-in needed, just looking for pins. Looks for outfits that have an Amazon affiliate link. Does not go to Amazon to check price or availability at this step.

2. TikTok Shop Agent

Searches TikTok Shop and picks the best products for you to make TikTok Shop videos about — demo-friendly, camera-friendly products that fit your audience. Brings back the product name, the product picture, why it fits, the TikTok Shop link exactly as shown, and the price exactly as shown on the listing, never a guess. Never buys or orders anything. On a TikTok Shop run it goes first, and its pick feeds the script and the video.

3. Image Agent

Creates the person and avatar images. Ultra realistic, real skin texture and real hair texture. Creates the character references, the outfit reference and the outfit reference sheet — all in chat, all PNG, all 9:16.

4. Story Agent

Writes the hook, the shots and the script. Labels every scene with the run's one Product Presentation choice. Writes scene action only for video prompts, never a description of the character.

5. Muse Video Agent

Makes the video right here in Muse with the built-in video maker — both references in every scene: Reference One headshot, Reference Two the chat-made outfit reference sheet. Returns the finished video in chat for approval. Never posts it.

6. Caption Agent

Writes the TikTok caption, on-screen hook and hashtags for posting. No price, discount or sale claim unless a live price was actually verified.

TikTok Shop runs

Pick the TikTok Shop videos mode and the run starts with the TikTok Shop Agent instead of the Pinterest Scout: it picks the best product for you, then the Image, Story, Muse Video and Caption agents build the whole TikTok Shop video around that product — script and all — under the same Product Presentation rule: wearing it or holding it, never both.

The Product Presentation rule — either / or, never both

Every run picks one single choice, right after Mode: Wearing the product or Holding the product.

Wearing run — every prompt ends: Wearing the product, not holding it.
Holding run — every prompt ends: Holding the product, not wearing it.

Never wearing an outfit while holding that same outfit on a hanger. Reject and regenerate any image that shows both. If a video needs both, holding first and wearing later — use separate scenes, never the same shot.

How Run in Chat works

Every Queue run gets a Run in Chat button. Pressing it sets that run to working and opens a Run in Chat card showing the locked character, both slot photos and their status, the voice, the mode, the Product Presentation choice and its exact prompt sentence, the topic, the length, and the product name and link. The card has a Copy prompt button. You paste that prompt into a new chat and Muse runs that exact run — nothing swapped. There is no scheduled pickup.

The workflow, step by step

  1. Pick the outfit on Pinterest. Choose the Pinterest outfit with an Amazon affiliate link. Copy its picture.
  2. Lock the outfit in chat first. Using the locked character's reference photos, put that character in that exact outfit in chat first. Check it for face match and outfit match.
  3. Make the outfit reference sheet in chat. From that approved outfit photo, create one single 9:16 reference sheet with front, profile and three-quarter shots of her in that outfit, all on the same photo. Save it as PNG.
  4. Load both references into every scene. Reference One is her headshot. Reference Two is that chat-made outfit reference sheet. Never make a scene without both.
  5. Create the scenes in Muse with the built-in video maker, from that headshot plus sheet lock, in script order, 9:16.
  6. Export and return the video in chat for approval. Do not post, publish or share it.

The character lock in Muse — every scene, every time

  1. Every scene is made in Muse with the built-in video maker, in chat — no outside video app.
  2. Reference One: headshot. Reference Two: the chat-made outfit reference sheet. Both references go into every scene generation — never a scene without both.
  3. No character bible is needed. The reference photos are the lock. Do not paste a bible into the scene prompts.

Use this prompt shape for every scene — and nothing else about her

Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it.

Never describe her in the prompt. No face, hair, skin, body or outfit description. Describing her overrides the references and creates a different girl. The last line swaps to the holding version when that is the run's choice.

Standing rules

Image format: Every image Muse creates must be PNG, not webp — character images, outfit references and outfit reference sheets. Your own uploaded Vault photos stay as you saved them, JPG or PNG. Webp uploads are rejected.

Characters: Ultra realistic, with real skin texture and real hair texture. Everything video- or character-related is 9:16 vertical — headshots, body reference sheets and scene shots. Character A is reused as Character A, Character B as Character B. Within one video, identity, clothing, location and lighting stay frozen from the uploaded reference photos.

Videos: All farm videos are made in Muse with the built-in video maker, right in chat — there is no outside video app in this farm and nothing is uploaded to one. Posting or publishing still needs your separate approval.

Video allowance: Muse's video tool runs on a daily allowance that refills on its own — not credits. There is nothing to buy, and no run pauses for credits.

Queue rule: The Queue status button only changes the label to queued, working or done. It does not run Pinterest, TikTok Shop, image generation or video making. Real execution is triggered from chat, using Run in Chat.
